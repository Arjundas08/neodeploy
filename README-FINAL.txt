🆘 IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════

1. Find Java process:
   Get-Process java

2. Kill it (replace PID):
   Stop-Process -Id <PID> -Force

3. Restart:
   java -jar target/neodeploy-0.0.1-SNAPSHOT.jar --server.port=9090

4. Wait 15 seconds

5. Open: http://localhost:9090/index.html
